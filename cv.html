A tool that assesses the environmental impact and resource use of packaging options. Report generation took 5–10 minutes on a pipeline that had run unchanged for three years inside a ten-year-old product.

The calculations lived in large, deeply nested SQL stored procedures that successive leads had worked around rather than touched. I moved them into the API layer behind a single source of truth and added Redis caching, using AI-assisted refactoring to make a change of that scope feasible for one developer. Reports now return in 5–10 seconds — roughly 60× faster. I identified the opportunity and delivered it proactively, without a client request, and lead a team of three on the product.

A deterministic context layer that lets AI coding agents make scoped, low-risk changes across large repositories instead of searching the whole codebase. It cut the context an agent loads per task from roughly 25,000 tokens to 800–1,000 — about 95% — verified with a side-by-side comparison test.

A plan / assess / validate guardrail loop computes each change's blast radius from a dependency graph and auto-escalates high-risk edits. It is model-agnostic and never calls an LLM itself, so any coding agent can consume it through its MCP server or CLI. There is a playable version of that idea below.

A platform for businesses to create and manage sign-up forms, surveys, promotions and audience analytics. I integrated the Google Gemini API for automated sign-up and survey generation plus AI-driven response analysis, alongside configurable automation workflows and QR-code embedding.

An ERP covering inventory, production, quality control, planning, finance and CRM. I developed and configured enhancements to the inventory and packaging modules to streamline operations — useful context for any product that has to exchange data with an ERP.
