Groundwork · try it

Before an agent edits a file, it should know what it can break.

Groundwork builds a dependency graph of a repository and computes each proposed change's blast radius from it, auto-escalating edits that reach too far. It cut the context an agent loads per task from roughly 25,000 tokens to 800–1,000 — about 95%, verified with a side-by-side comparison test.
